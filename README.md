# Badminton Manager

เว็บแอปจัดคิวก๊วนแบดมินตัน — ไฟล์เดียว (`index.html`) เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้ (localStorage)

## ใช้งาน

1. เปิด `index.html` ในเบราว์เซอร์
2. **📋 เพิ่มหลายคน** → วางข้อความประกาศก๊วนทั้งก้อน ระบบดึงบรรทัด `1. ชื่อ` ให้เอง
3. ปรับแรงก์คนหน้าใหม่ → ตั้งจำนวนสนาม → **⚡ จัดอัตโนมัติ**
4. จบเกมด้วย **✅ จบเกม** แล้วจัดใหม่ได้ทันที
5. สัปดาห์ถัดไป: โหมด Admin → **🆕 เริ่มก๊วนรอบใหม่** (ล้างประวัติ เก็บรายชื่อและแรงก์ไว้)

ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น — ย้ายเครื่องหรือเก็บสำรองด้วย **⬇️ สำรองข้อมูลเป็นไฟล์** / **⬆️ กู้คืนจากไฟล์** (โหมด Admin)

## ฟีเจอร์

- **จัดคู่อัตโนมัติ 3 ชั้น** — ลองกฎเต็มก่อน แล้วผ่อนทีละชั้นจนจัดได้เสมอ ความยุติธรรมของจำนวนเกมมาก่อนทุกอย่าง
- **ระดับมือ** BG / N / M / H / S และ F (สลับ H↔M เองทุก 3 เกม)
- **เกมพี่เลี้ยง** หมุนมือหนักให้มือ N ไม่ซ้ำหน้า · **โหมดซ้อมทีม** ล็อกคู่ซ้อมกับคู่แข่งที่เลือกไว้ · **คิวจอง** · **จัดมือเอง**
- **กฎคู่บุคคล** — ห้ามเจอกัน / ต้องคนละทีม / ทีมเดียวกันเสมอ
- **คนมาสาย** ได้แต้มต่อเท่าคนเล่นน้อยสุด (ปุ่มคัดลอกรายชื่อให้จำนวนเกมจริงสำหรับคิดเงิน)
- **สถิติ**, ตาราง **H เจอ N**, Encounter Matrix, ประวัติพร้อมคัดลอกส่งกลุ่ม, ส่งออก CSV

## หมายเหตุ

- หน้าตาใช้ Tailwind CSS ผ่าน CDN — ถ้าไม่มีอินเทอร์เน็ต หน้าตาจะเพี้ยนแต่ทุกฟังก์ชันยังใช้งานได้
- ค่าคะแนนของตัวจัดคู่อยู่ที่ `SCORE` ใน `index.html` จุดเดียว
